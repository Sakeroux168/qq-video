# qq-video · 企鹅号发布助手

在「创作罐头」里给企鹅号一批批摆好视频,**停在发布前,发布由人自己点**。

## 一天怎么用

1. 打开创作罐头(登录着企鹅号),再打开本软件。
2. 上面「要发哪天的」选日期(软件不自动挑最新的,员工可能提前建好以后的日期)。
3. 左边勾上要发的员工文件夹,中间列出这些视频,每条写着封面框对准了谁、为什么。
   - 没有人的封面(拍东西、背影),框对准画面里的主体;标黄的是连主体都找不出来的,摆好后在罐头里看一眼。
   - **双击一条(或点「预览 / 调封面…」)**:看每个比例的裁剪框,不满意就在大图上拖框、或者恢复自动;
     调过的记在 `封面调整.json`,关了软件再开还在,摆的时候按你调的位置拖。
4. 点「摆下一批」:软件在罐头里打开这个号的发布页,一次传最多 10 条,每条:
   传视频 → 传封面 → 依次裁好每个比例(框拖到人中间)→ 自主声明「无需标注」→ AI 生成声明「提交」。
   摆的时候别在罐头里切到别的号。
5. 去罐头里检查,没问题就把鼠标移到「发布」上,点「全部发布」。
6. 回软件点「这批发好了」(记下发布时间),再点「摆下一批」……
7. 一天全发完,点「这天发完了,挪走」:整个日期文件夹剪切到 `X:\知乎视频\内容查看\<月>月发布视频\企鹅号\教育\`。

「记录」页签:每条哪个员工的、什么时候发的;按员工汇总;能导出 Excel。时间一律按北京时间(不管电脑时区)。

## 素材文件夹

```
X:\知乎视频\小学生教育\<日期,如 10.15>\<号的缩写>\<员工>\
    标题.mp4   视频(文件名就是发出去的标题)
    标题.png   无字封面(用这个)
    标题.jpg   原封面,带字(不用)
```

员工「梁」的放法也认:`<员工>\封面\<视频标题>\横屏16x9.png`(没有就用 `修改 (1).png`;`原图.png` 带字不用;
`竖屏9x16.png` 先认出来记着)。视频名和封面文件夹名里空格、下划线、标点对不齐也认。

右键列表 / 「打开所在文件夹」:在资源管理器里打开并选中这条视频(或封面);右键左边员工打开那个文件夹。

号和缩写在「设置」里改:`家长研习空间=研习空间、研习社`、`家长小天地=小天地`。

## 封面规矩

- **只用 png(无字版)**。jpg 是原封面、上面有字,不能用(组长说的);没有 png 的标黄,让员工补。
- 一个人:每个比例的裁剪框拖到他中间。
- 几个人挨得近、最窄的 9:16 框装得下:框对准他们中间。
- 几个人:每个比例框得下所有人就对准他们中间;框不下的窄比例(一般是 9:16)对准脸最大的那个,标黄看一眼。
- 没有人(拍东西、背影):框对准画面主体(颜色和背景差得最多的那块)。
- 封面图短边不到 540 像素企鹅号不收(「封面图尺寸过小」):软件放大到 720 再传(会有点糊)。

认人用本机的 OpenCV YuNet 人脸模型(`models/face_detection_yunet_2023mar.onnx`,来自 [opencv_zoo](https://github.com/opencv/opencv_zoo),MIT 许可),不联网。

## 接口发(16 个游戏 / 动漫号)

「接口发(16个号)」页:用企鹅号官方接口直接发,不用罐头(照搬旧软件「企鹅号批量发布」)。

- 素材:`X:\知乎视频\游戏视频\<游戏>--<昵称>\<日期…>\`、`X:\知乎视频\动漫视频\<昵称>\<日期…>\`;只认「月.日」开头的文件夹(「10.15(20)」「10.14（星期三）」都行),「不能用」「脏话」「已发」等不碰。
- 账号:点「从旧软件搬账号…」从 `qepm.db` 搬,密钥用 Windows DPAPI 加密存在 `%LOCALAPPDATA%\企鹅号发布助手\接口账号.json`。
- 先「检查」:横屏(一键转竖,原片进「横屏原片」)、标题里有别的平台的名字(只标黄,自己改)、话题不止一个(AI 留一个,和 ainame「只筛话题」一样,能撤销)。
- 「发能发的」:标题 = 简介 = 文件名,分类按号,声明非 AI,封面平台自己截;发成了挪到 `X:\知乎视频\内容查看\{月}月发布视频\企鹅号\企鹅号软件发布`,记进「记录」(员工一栏 = 接口)。

## 红线

罐头那边软件**绝不点「发布 / 定时发布 / 存草稿」**(只有勾了「摆好后软件自己点全部发布」才点):所有点击都过一道检查,带这些字的一律拒绝(`qe/prepare.py` 的 `_guard`,测试里也查)。

## 开发

```
pip install -r requirements.txt
python main.py                                   # 运行
PYTHONIOENCODING=utf-8 python tests/test_basic.py # 测试(不连罐头)
python -m PyInstaller --noconfirm 企鹅号发布助手.spec  # 打包,出来在 dist\企鹅号发布助手\
```

数据(设置、发布记录、截图)在 `%LOCALAPPDATA%\企鹅号发布助手`;测试时设 `QE_DATA_DIR` 指到临时目录。

罐头里每个号的页面是 webview,Playwright 看不到,所以直接用调试口(CDP)发命令(`qe/cdp.py`)。
