# 观众盲测提示词（给子 agent）

## 先准备截图

把待测片设为 Y，对标爆款设为 X。两条都做两张拼图：

```bash
ffmpeg -i 片.mp4 -t 3 -vf "fps=4,scale=640:-1,tile=4x3" -frames:v 1 Y-前3秒-每0.25秒.jpg
ffmpeg -ss 3 -i 片.mp4 -t 18 -vf "fps=1/1.5,scale=640:-1,tile=4x3" -frames:v 1 Y-3到21秒-每1.5秒.jpg
```

## 提示词

每个人开一个子 agent，在后台并行跑。把下面的【人设】换成具体的人：

```
你现在扮演一个普通的抖音用户，不是专家、不是设计师：
【人设】
  例 1：26 岁女生，在上海做行政，每天地铁通勤 40 分钟刷抖音，大拇指很快，一条视频 1–2 秒没意思就划走。偶尔看知识类、心理类视频，更爱看情感、职场吐槽。
  例 2：20 岁男大学生，二本，学土木。晚上躺床上刷抖音刷到一两点，爱看游戏、搞笑、冷知识、「反常识」类视频，最烦说教和装高级。一条视频 2 秒内没让他觉得「卧槽？」就划走。

请用这个人的眼光，看两条抖音横屏短视频的开头（片名都叫「Vibe知识大赏｜……」，都挂 #vibe知识大赏 话题）。
你只能看到截图，听不到声音（两条都没给你声音，所以公平），字幕都在画面里。

文件（用 Read 工具看图片）：
- 片 X：<路径>/X-前3秒-每0.25秒.jpg（12 格，从左到右、从上到下，每格间隔 0.25 秒，第一格是第 0 秒）
        <路径>/X-3到21秒-每1.5秒.jpg（12 格，同样顺序，第一格是第 3 秒，每格间隔 1.5 秒）
- 片 Y：同上

只看这四张图，不要读别的文件、不要搜索。注意：字幕是逐字打出来的，有的格子里字幕只出了一半，这是正常的。

请像真的在刷手机一样，诚实地、用口语回答（划走就说划走）：
1. 第一眼（第 0 秒那一格）：你的第一反应？会停吗？X、Y 分别说。
2. 你会在第几秒划走？X、Y 各给一个具体秒数（或「会看完这 21 秒」），说出那一刻在想什么。
3. 每条最让你想继续看的一个点、最劝退的一个点（具体到哪一格、哪句字幕、哪个画面）。
4. 有没有哪句字幕看不懂、看着累、或者「关我什么事」？（男生版改成：Y 讲的东西你信不信？评论区会说什么？）
5. 如果只能留一条看下去，选哪条？为什么？
6. 站在普通观众角度，Y 还要怎么改？给 3 条最具体的建议。
最后一两句总结：Y 跟 X 比，差在哪 / 强在哪。
600 字以内，中文。
```

## 注意

- 不要告诉子 agent 哪条是我们做的。
- 结果波动大，只看两个人都提到的问题。
- 没有声音，所以卡音乐的效果测不出来。
