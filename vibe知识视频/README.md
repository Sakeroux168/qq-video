# Vibe知识视频 · 交接文档（给接手的 agent）

> 这个分支（`vibe-knowledge-video`）专门做「用代码生成的抖音知识短片」。本仓库原来的主业是「企鹅号发布助手」，那部分的交接看根目录的 `交接文档.md`，和这里无关。

## 一句话

照抖音 **#vibe知识大赏** 话题的爆款做法，用 Claude 写代码逐帧画出知识短片。所谓逐帧画，就是用 Canvas 动画把每一帧截成图，再配上 BGM 和音效，合成 mp4。

第一个系列是 **「七宗罪」**。第一集「嫉妒」已经做到 v3.1。

## 接手先做什么：v3.2 方案（音乐和两次重拍不动）

先问用户要不要做。点头后照下面改 `七宗罪/src/film2.html` 和 `sound_film2.py`：

1. **删掉讲古的那三小节**（B1–B3：赫西俄德、乞丐、国王）。「隔壁」砸下来之后直接接脑扫描实验。赫西俄德只留在片尾的参考资料里。
2. **「隔壁」下面那行小字改成大白话**：「身边、跟你差不多的人」，去掉英文 Social Comparison。
3. **开头重排**：
   - 0–2 秒三条消息连弹：「室友：保研了」「闺蜜：订婚啦」「前任：最近过得挺好」，第 1.5 秒你倒地。
   - 2.3 秒：首富多赚一百亿，你没感觉。
   - 4.4 秒：兄弟提了辆车，你一夜没睡。
   - 6.6 秒：「既怕兄弟过得苦，又怕兄弟开路虎」。
   - 之后：「你嫉妒的永远是那几个人：同一个宿舍、同一个工位、同一个群」，再接「你只嫉妒——」。
   - 删掉「心里，像被扎了一下」，男观众嫌它像说教。
4. **消息气泡和人名标签放大约 50%**，手机上要看得清。现在正文 32px、名字 22px。
5. 腾出来的小节，给「嫉妒的地图」多加两句，比如「同一个起点的人，跑到了你前面」。
6. 改完：渲染关键帧自查，重点看两次重拍（17.455 秒、95.532 秒）前后的帧。然后出片、提交。**建议不再盲测，直接发**，真实完播率比模拟观众准。

## 怎么出片（复现）

```bash
cd vibe知识视频/七宗罪/src
npm i                                   # 装字体（npm 能连上）
node render.js film2 111 --stills 0,17.5,95.6   # 只出几张静帧，存到 stills/
node render.js film2 110.7              # 出全部 3321 帧到 frames/，约 6 分钟
ffmpeg -i bgm.mp3 -ar 48000 -ac 2 bgm48.wav     # BGM 文件见下面「BGM」一节
python3 sound_film2.py bgm48.wav film2.wav
ffmpeg -framerate 30 -i frames/%05d.jpg -i film2.wav -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4
```

- 需要 Node（Playwright 环境里已经有，`require('playwright')` 直接能用）、ffmpeg、Python 的 numpy 和 scipy。
- 画面完全由时间 `t` 决定，所以任意时刻都能单独渲染出来检查。
- 时间轴卡在 BGM 的小节线上：`小节 B(k) = 17.455 + k × 2.1688` 秒，`D1 = 17.455`，`D2 = 95.532`（就是 B(36)）。

## BGM

- 用户给的文件叫 `10_28_.mp3`，158.112 秒，48kHz，320kbps，从剪映音乐库导出。**疑似《千年之后》氛围版**，和参考帖 2 用的是同一首。
- **没提交进仓库**：本仓库是公开的，这首歌可能有版权。下一个 agent 要渲染，就向用户要这个文件。
- 实测结果：
  - 四分音符 0.5422 秒（约 111 BPM），一小节 2.1688 秒。
  - 第一次「换气」在 16.45–17.40 秒，重拍落在 17.455 秒。
  - 第二次「换气」在 94.6–95.45 秒，重拍落在 95.532 秒。
  - 段落：0–17 秒前奏；17–48 秒强；48–79 秒中；79–95 秒安静；95–156 秒强。
- ⚠️ 已提交的 `嫉妒-v3*.mp4` 里混着这首 BGM，而仓库是公开的。要不要从仓库里删掉，**等用户决定**。

## 云端环境的限制（这次会话踩到的）

- **打不开**：知乎、豆瓣、小红书、抖音、B站、微博、X、github.io、HuggingFace、ideas.repec.org、微软 TTS（speech.platform.bing.com）。
- **能用**：WebSearch（只能看到摘要）、npm、PyPI、GitHub 匿名 clone。
- **所以配不了音**：Kokoro 模型下载不了，edge-tts 也连不上。现在的做法是**纯音乐 + 字幕当旁白**，参考帖 2 也是这么做的。
- 中文字体用 npm 的 `@fontsource/noto-serif-sc` 等包，系统里只有文泉驿。

## 用户偏好（很重要）

- 用户说中文。要大白话，普通人看完会说「嗯，说得对」，**最烦说教和掉书袋**。
- 画风：用户看过 lemo-opuscar 的 66 种风格，**一个都没看上**。自己选的是照爆款《知识诅咒》扒的暗金风；我画过的 4 种新方向，用户觉得「1 和 2 不错」，但最后还是选了知识诅咒风。
- 用户会自己看片。说「不吸引我，我直接就退了」的时候，要换剧本，不要只修小细节。
- 用户喜欢用「子 agent 扮演普通观众」做盲测（模板在 `工具/观众盲测提示词.md`）。
- lemo-opuscar 已经收藏在用户的 `Sakeroux168/skill-home` 仓库，目录是 `skills/柠檬opus/`。
- 发企鹅号时，标题里不能出现「抖音」「@抖音科技」「#抖音…」，发布助手的 `qe/checks.py` 会把它标成「别的平台」。
