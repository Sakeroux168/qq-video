# qq-video · 企鹅号发布助手

两条线,一个软件:
- **教育号**(家长研习空间、家长小天地):在「创作罐头」里一批批摆好视频,**停在发布前,发布由人自己点**(可选:勾「摆好后自动点发布」)。
- **16 个游戏 / 动漫号**:用企鹅号官方接口直接发(照搬旧软件「企鹅号批量发布」),发之前一定弹框让人点「发」。

双击 `启动.bat` 打开(只能开一个)。

## 教育号:一天怎么用(「发视频(教育,罐头)」页)

1. 打开创作罐头(登录着企鹅号),再打开本软件。
2. 上面「要发哪天的」选日期(软件不自动挑最新的,员工可能提前建好以后的日期)。
3. 左边勾上要发的员工文件夹,中间列出这些视频,每条写着封面框对准了谁、为什么。
   - 没有人的封面(拍东西、背影),框对准画面里的主体;标黄的是连主体都找不出来的,摆好后在罐头里看一眼。
   - **双击一条(或点「预览封面…」)**:看每个比例的裁剪框,不满意就在大图上拖框、或者恢复自动;
     调过的记在 `封面调整.json`,关了软件再开还在,摆的时候按你调的位置拖。
   - 没有无字封面(png)的先跳过,不挡后面的(确认框里会说跳过了几条)。
4. 点「摆下一批」:软件在罐头里打开这个号的发布页,一次传最多 10 条,每条:
   传视频 → 传封面 → 依次裁好每个比例(框拖到人中间)→ 自主声明「无需标注」→ AI 生成声明「提交」。
   摆的时候别在罐头里切到别的号。摆到一半点了「停」/ 出错,已经摆好的那几条照样等你确认。
5. 去罐头里检查,没问题就把鼠标移到「发布」上,点「全部发布」。
6. 回软件点「这批发好了」(记下发布时间),再点「摆下一批」……
7. 一天全发完,点「这天发完,挪走…」:整个日期文件夹挪到 `X:\知乎视频\内容查看\<月>月发布视频\企鹅号\教育\`。
   一个文件一个文件挪,被别的程序占着的留在原处并告诉你是哪个,关掉再点一次接着挪,不会两边各一份。

「记录」页签:每条哪个号 / 员工的、什么时候发的、没发成的原因;按员工汇总(已发 / 没发成 / 结果不明);能导出 Excel。时间一律按北京时间(不管电脑时区)。

## 素材文件夹(教育)

```
X:\知乎视频\小学生教育\<日期,如 10.15>\<号的缩写>\<员工>\
    标题.mp4   视频(文件名就是发出去的标题)
    标题.png   无字封面(用这个)
    标题.jpg   原封面,带字(不用)
```

员工「梁」的放法也认:`<员工>\封面\<视频标题>\横屏16x9.png`(没有就用 `修改 (1).png`;`原图.png` 带字不用;
`竖屏9x16.png` 先认出来记着)。视频名和封面文件夹名里空格、下划线、标点对不齐也认。

号和缩写在「设置」里改:`家长研习空间=研习空间、研习社`、`家长小天地=小天地`。

## 封面规矩(教育)

- **只用 png(无字版)**。jpg 是原封面、上面有字,不能用(组长说的)。
- 一个人:每个比例的裁剪框拖到他中间。
- 几个人:每个比例框得下所有人就对准他们中间;框不下的窄比例(一般是 9:16)对准脸最大的那个,标黄看一眼。
- 没有人(拍东西、背影):框对准画面主体(颜色和背景差得最多的那块)。
- 2.35:1 的标题区会压字:挪框 → 切一点头顶 → 还挡脸才 AI 扩图(阿里百炼)。
- 封面图短边不到 540 像素企鹅号不收:软件放大到 720 再传(会有点糊)。

认人用本机的 OpenCV YuNet 人脸模型(`models/face_detection_yunet_2023mar.onnx`,来自 [opencv_zoo](https://github.com/opencv/opencv_zoo),MIT 许可),不联网。

## 16 个游戏 / 动漫号(「接口发(16个号)」页)

- 素材:`X:\知乎视频\游戏视频\<游戏>--<昵称>\<日期…>\`、`X:\知乎视频\动漫视频\<昵称>\<日期…>\`;只认「月.日」开头的文件夹(「10.15(20)」「10.14（星期三）」都行),「不能用」「脏话」「已发」等不碰。没日期文件夹的号(电竞情报馆的「2电竞赛事」)用「给号选文件夹…」(旧软件的「选择」)。这天没找到视频的号灰着列出来。
- 账号:点「搬账号…」从旧软件的 `qepm.db` 搬,密钥用 Windows DPAPI 加密存在 `%LOCALAPPDATA%\企鹅号发布助手\接口账号.json`,日志里不会出现密钥。
- **选中规则**:选了就只管选中的(点号那一行 = 这个号全部,Ctrl / Shift 多选),没选就管看得见的全部;下面绿字写着这次管几条。Esc 取消选择。
- 选日期后自动检查(横屏 / 标题里有别的平台 / 话题多个或写法不对 / 结尾多空格);检查过的刷新后不用再查。
- 处理:「转标准竖屏」(横屏、偏方的 3:4 / 正方形都转成 1080×1920,原片进「横屏原片」)、「整理话题」(写法按固定规矩改;挂好几个话题的 AI 留一个,和 ainame「只筛话题」一样)、「批量改话题…」(先选,全换成你填的那个)、右键「改标题」(F2)。改名都能「撤销上次改名」(一次操作一批;发过的不改回)。
- 「发布」:弹框按号列出条数、分类、预计时间,点「发」才发。标题 = 简介 = 文件名;自主声明「无需标注」;AI 声明「非 AI 生成」;封面平台自己截;一条一条发,上一条发完歇 5 秒。发成了挪到 `X:\知乎视频\内容查看\{月}月发布视频\企鹅号\企鹅号软件发布\<游戏名>\`,记进「记录」(员工一栏 = 接口)。
- 状态颜色:绿 = 已发;红 = 没发成(行里写原因,鼠标悬停看原话)/ 横屏;黄 = 有问题;**橙 = 结果不明**(请求发出去了没收到回话,或者发到一半软件被关了)—— 软件不会再自动发它,去后台看一眼再右键标「发了 / 没发」。
- 某个号密钥坏了:第一条报「号的密钥不对」,剩下的标「没轮到」;发完弹总结(成功 / 没发成 / 结果不明 / 没轮到)。
- 快捷键:F5 刷新、Ctrl+F 搜标题、Esc 取消选择、F2 改标题。

## 红线

- 罐头那边软件**绝不点「发布 / 定时发布 / 存草稿」**(只有勾了「摆好后自动点发布」才点):所有点击都过一道检查,带这些字的一律拒绝(`qe/prepare.py` 的 `_guard`,测试里也查)。
- 接口那边每次发布都要人在确认框点「发」;已发 / 结果不明的不会自动再发(防重发按记录库查,路径大小写 / 斜杠写法不同也认得)。
- 挪文件只走 `qe/fsops.py`(不用 shutil.move),设置只写改过的项,坏了的设置 / 记录库改名留底。

## 开发

```
pip install -r requirements.txt
python main.py                                   # 运行
PYTHONIOENCODING=utf-8 python tests/test_basic.py # 测试(不连罐头、不联网,不弹框)
```

数据(设置、发布记录、截图、改名台账)在 `%LOCALAPPDATA%\企鹅号发布助手`;测试时设 `QE_DATA_DIR` 指到临时目录。

罐头里每个号的页面是 webview,Playwright 看不到,所以直接用调试口(CDP)发命令(`qe/cdp.py`)。
企鹅号接口的实际行为和文档有出入(都在 `qe/omapi.py` 注释里):分片 end_offset 含最后一个字节;vid 在 data.vid;ext_info 要 JSON。
